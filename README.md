# Expense Tracker App

A simple React-based Expense Tracker that uses local storage to save data. 

Features:
- Add, edit, and delete expenses
- Filter expenses by month
- Display total expense amount
- Local storage persistence
- Responsive design

# Tech Used:
- React (Vite)
- JavaScript (ES6+)
- CSS

# Setup
1. npm install
2. npm run dev
